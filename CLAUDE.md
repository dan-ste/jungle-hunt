# Jungle Hunt

A "Where's Waldo" style game. Our teammates are drawn as cartoons and hidden in a Costa Rica jungle full of animals. The player looks around the scene and clicks each teammate to find them.

This is a hackathon project. Several people work on it at the same time, each with their own Claude Code on their own machine. This file is the only context every Claude shares, so keep it up to date.

## Team rules

- Get each person's OK before adding their cartoon.
- Pull `main` before starting each task.
- One branch per task: `<name>/<short-task>`. Small PRs. Merge to `main` at least every hour or two.
- Do not add a dependency or change a shared format without telling the team.
- When you learn something every Claude should know, add it to this file in the same PR.
- Personal notes go in `CLAUDE.local.md` and personal settings in `.claude/settings.local.json`. Both are git-ignored.
